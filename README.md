# 🏓 1D Pong на Arduino & NeoPixel (WS2812B)

**1D Pong** — це динамічна однокористувацька аркадна гра в одновимірному просторі на базі мікроконтролера Arduino та світлодіодної стрічки/матриці WS2812B. Гравець керує ракеткою за допомогою аналогового джойстика, відбиваючи м'яч та контролюючи його швидкість за допомогою додаткової осі підкручування.

---

## 🎮 Ігровий процес та особливості

* 🔴 **Червоний піксель (М'яч)** — летить у напрямку до ракетки (небезпека).
* 🟢 **Зелений піксель (М'яч)** — успішно відбитий і летить до протилежної стіни.
* 🟦 **Синя ракетка** — звичайний режим руху ракетки.
* 🟪 **Пурпурна ракетка** — режим «супер-прискорення» м'яча.
* 🩵 **Блакитна ракетка** — режим «сповільнення / хитний фінт».
* 🚨 **Червоні спалахи** — анімація Game Over при пропуску м'яча.

### 🕹️ Керування:
* **Вісь X (Вліво / Вправо):** Плавне переміщення ракетки вздовж ігрової зони.
* **Вісь Y (Вгору / Вниз):** Механіка підкручування м'яча в момент відбивання:
  * **Натискання вгору/вперед:** Додає м'ячу високу швидкість (складніше для наступного удару, але цікавіше).
  * **Натискання вниз/назад:** Сповільнює м'яч для повернення контролю над грою.

## 🔌 Схема підключення

### 1. Світлодіодна стрічка NeoPixel (WS2812B)
* **DIN (Data In)** $\rightarrow$ Digital Pin **12**
* **5V / VCC** $\rightarrow$ **5V** на Arduino
* **GND** $\rightarrow$ **GND** на Arduino

### 2. Аналоговий джойстик
* **VRX (Вісь X)** $\rightarrow$ Analog Pin **A0**
* **VRY (Вісь Y)** $\rightarrow$ Analog Pin **A1**
* **VCC** $\rightarrow$ **5V**
* **GND** $\rightarrow$ **GND**
